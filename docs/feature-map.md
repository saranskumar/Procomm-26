# Feature Map

The PROCOMM '26 website will be a single-page interactive application with a custom retro-style loading intro.

## Pages & Screens

### 1. Interactive Intro / Loading Screen
- **Visuals**: Matches Image 2 closely (Cream/beige background, "IEEE COMSOC KERALA CHAPTER PRESENTS", large 3D-shaded "PROCOMM '26" logo, "loading..." label, and an animated brown loading progress bar).
- **Behavior**: Simulates an organic load sequence (0 to 100%), then smoothly transitions (fade & slide out) to reveal the main landing page. A "Skip Intro" option is available.

### 2. Main Landing Page
- **Header**:
  - Contains IEEE ComSoc Kerala Chapter, IEEE Kerala Section, and IEEE official branding logos.
  - Sticky navigation with retro borders.
- **Hero Section**:
  - High-impact display of the 3D-shaded "PROCOMM '26" logo.
  - Subtitle: "IEEE COMMUNICATIONS PROJECT COMPETITION".
  - Fine-line vector drawing/sketch of a campus/building in the background.
  - "The line is open. Is your campus ready?" tagline.
- **Call for Host (Active CTA)**:
  - Retro double-border card matching the visual template in Image 1.
  - "APPLY NOW" button (redirects to the host application form).
  - "DEADLINE" section showing "2nd July 2026".
- **About Section**:
  - Detailed introduction to PROCOMM (IEEE Communications Project Competition).
  - Objectives: Fostering innovation in telecommunications, networking, and related fields.
- **Tracks & Themes**:
  - Interactive grid displaying the technology domains of the competition:
    - 5G/6G & Next-Gen Wireless
    - IoT & Smart Systems
    - Optical & Satellite Communications
    - Network Security & Cryptography
    - AI & ML in Communications
- **Host Benefits Section**:
  - What a host institution gains (visibility, networking, student exposure).
- **Contact & Inquiries Section**:
  - A functional form for campuses interested in hosting or students asking questions.
  - Retro-styled inputs (thick borders, cream background, crisp focus transitions).
- **Footer**:
  - Links: `comsoc.ieeekerala.org`
  - Social icons/links: Facebook, Instagram, X (Twitter), LinkedIn (`/ieeecomsocks`).
  - IEEE & ComSoc copyright notices.
