# Technology Stack

## Core
- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Custom CSS (to match the retro sketch aesthetic)
- **Icons**: Lucide React
- **Animations**: Framer Motion (for retro-themed loading screens, transitions, and hover micro-animations)

## Client / Server State
- **State Management**: React state / Context (minimal, as this is mainly a marketing and landing site)

## Validation
- **Validation**: Zod (for application forms)

## Dev & Tools
- **Package Manager**: npm / pnpm (system default)
- **Deployment**: Vercel / Standard Next.js
